[ 01 ]Get to the Windows setup screensAccount~10 min▾
  • New / fresh install: Media Creation Tool → bootable USB (8GB+) → boot → Custom Install → wipe all partitions.
  • Already has Windows: Settings → System → Recovery → Reset this PC → Cloud Download (clean copy from Microsoft, no factory bloatware).

Both land on the same screens. One flow from here:

  1. Language, region, keyboard — pick yours, skip a second layout.
  2. Network screen: don't connect to WiFi.
  3. Focus the setup window, Shift + F10 for a command prompt.
  4. Type this:
    CMD
    start ms-cxh:localonly
    Opens local-account setup — no Microsoft server, no cloud sync, manual password recovery.
  5. Username, blank password — set a real one later inside Windows.
  6. Privacy screen → no to everything: Location, Find My Device, diagnostics, inking & typing, tailored experience, Advertising ID, presence sensing.
  7. You're in. Bloatware on the desktop gets handled in Step 09.

Fallback if ms-cxh:localonly ever breaks:

CMD — fallback
reg add HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\OOBE /v BypassNRO /t REG_DWORD /d 1
shutdown /r /t 0

Reboot → "I don't have internet" → local account.

[ 02 ]Windows UpdateSystem~20 min▾

Several rounds, back to back, restart between each, until nothing new shows up.

[ 03 ]Confirm the exact modelSystem~1 min▾
POWERSHELL
Get-CimInstance -ClassName Win32_ComputerSystem | Select-Object Model

More reliable than the sticker on the bottom. Use this exact string to find the support page.

[ 04 ]BIOS updateFirmware~10 min▾

Check the currently installed version first:

POWERSHELL
(Get-CimInstance Win32_BIOS).SMBIOSBIOSVersion
  1. Go to the manufacturer's official support site.
  2. Search your exact model.
  3. Open the BIOS / Firmware section.
  4. Compare the listed version against the one from the command above.
  5. If newer, download and run the update — keep the machine plugged in, don't interrupt it.
  6. Reboot, re-run the command above to confirm the new version took.
[ 05 ]DriversDrivers~15 min▾

On the manufacturer's support site, Drivers tab, in order:

  1. Chipset
  2. GPU — if it's an Nvidia dGPU (most common on gaming laptops), skip the manufacturer's page and go straight to nvidia.com/drivers instead: select your exact GPU model, product series, and OS → download → Custom Install → check "Perform a clean installation" → Game Ready by default (Studio only for certified software, e.g. Adobe/Maya).
  3. Audio, WiFi, Bluetooth, touchpad
  4. Manufacturer's low-level system driver — needed for the control-app step further down

Check Device Manager after — clear any yellow warnings.

[ 09 ]Bloatware sweepCleanup~15 min▾

revouninstaller.com → install, open it side by side with Settings → Apps → Installed apps.

  1. Scan both lists for anything you don't use.
  2. Common candidates: trial antivirus (McAfee, Norton), unused Xbox apps, Phone Link, OEM companion/bloat apps.
  3. Uninstall through Revo, not Windows directly — it catches leftovers the normal uninstaller skips.
  4. After each removal, let Revo run its leftover scan (registry keys, empty folders) and clear what it finds.
  5. Repeat until both lists only show things you actually use.
Hard ruleNever remove anything named runtime or redistributable — .NET Runtime, Visual C++ Redistributable, WebView2 Runtime. Other apps depend on these even if the name looks unfamiliar.
[ 10 ]Replace manufacturer softwareSoftware~5 min▾

Manufacturer control apps (fan curves, battery, performance modes) are usually bloated. Confirmed, reliable community alternatives by brand:

  • ASUS (Armoury Crate + MyASUS) → G-Helper
  • Lenovo Legion (Vantage / Legion Zone) → Lenovo Legion Toolkit (LLT)
  • MSI (MSI Center, fan curves specifically) → Fan Control

[ 12 ]Backup — Google DriveCloud~10 min▾

google.com/drive/download → install → sign in.

  1. When asked how to sync, you'll see two sections: "Google Drive" (mounts your whole Drive as a virtual disk) and "My computer" (backs up specific folders from this PC to the cloud). You want the second one.
  2. Under "My computer" → Add folder → pick the specific lightweight folder(s) you want protected. Not the whole drive, not your Downloads.
  3. Leave photo/video quality options unchecked unless that folder actually has heavy media.
  4. Confirm. It syncs in the background from here on, every time something in that folder changes.
[ 13 ]Development environmentDev~20 min▾

ORDER Git → VS Code → Python → GitHub Desktop → Claude Code.

Git — git-scm.com → install. Key installer choices:

  • Default branch name → override to "main" (GitHub's standard since 2020, saves renaming every repo)
  • PATH → "Git from the command line and also from 3rd-party software" (the recommended middle option)
  • SSH → bundled OpenSSH
  • HTTPS backend → OpenSSL library (Secure Channel is only for company-managed certificates)
  • Line endings → "Checkout Windows-style, commit Unix-style" (the Windows-recommended default)
  • Terminal → MinTTY
  • Default editor when it asks → pick anything for now (Nano if given the choice) — overridden in the VS Code step below anyway
  • Default git pull behavior → "Fast-forward only" (safest for solo work — stops and tells you instead of guessing)
  • Credential helper → Git Credential Manager
  • Extra options → enable both (file system caching, symbolic links)

Then set your identity (own line, copy exactly, swap in your details):

POWERSHELL
git config --global user.name "Your Name"
git config --global user.email "you@email.com"

VS Code — code.visualstudio.com → install, check "Open with Code" for both files and folders in the installer, skip the desktop icon. Extensions to add (Ctrl+Shift+X): Python (Microsoft) and GitLens. Then set it as Git's default editor:

POWERSHELL
git config --global core.editor "code --wait"

Python:

POWERSHELL
winget install Python.Python.3.13

GitHub Desktop — desktop.github.com → install → sign in with (or create) a GitHub account. Confirms/fills your Git identity from the account.

Claude Code — requires a Claude Pro plan or higher.

POWERSHELL
irm https://claude.ai/install.ps1 | iex
ContainmentNever use --dangerously-skip-permissions on your own machine. Always launch claude from inside the specific project folder, never from your whole user folder. Use claude --plan the first few times to review everything before it touches a file.

DAILY FLOW Write/ask Claude Code to write → test in the integrated terminal → GitHub Desktop: write a commit message → Commit to main → Push origin. Repeat.
