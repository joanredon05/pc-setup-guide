# PC Setup Guide

A personal, reusable checklist for setting up a Windows PC from scratch — debloating, privacy configuration, drivers, and a curated, checkable app list. Built as a single self-contained HTML file: no build step, no dependencies, just open it in a browser.

## What's inside

- Step-by-step Windows setup — clean install or reset, local account, updates
- Debloat and privacy configuration (WinUtil, O&O ShutUp10)
- BIOS and driver update workflow
- Manufacturer software replacement (lightweight community alternatives per brand)
- A categorized app checklist with persistent progress — check things off as you install them, saved automatically in the browser
- Google Drive backup setup
- Development environment setup — Git, VS Code, Python, GitHub Desktop, Claude Code
- A growing keyboard shortcuts reference

## How to use it

Open `pc_setup_guide.html` in any browser. Follow the steps in order, check off apps as you install them — progress is saved locally, no account needed. Copy commands straight from the code blocks with the built-in copy button.

## How to edit it

Plain HTML, CSS, and JavaScript — no build tools, no framework. Open it in any code editor and change the text, colors, or app list directly. The `App list` and `Keyboard shortcuts` sections are meant to be updated per device.

## Why this exists

Setting up a new machine well takes real research — figuring out which OEM software to skip, which community tool replaces it, which settings are worth touching. This exists so that research doesn't have to be redone from scratch every time, on this machine or the next one.
