# PC Setup Guide

A personal, reusable checklist for setting up a Windows PC from scratch:
debloating, privacy configuration, drivers, and a curated app list you can check
off as you go. Built as a single self contained HTML file, with no build step and
no dependencies.

Open it here: https://joanredon05.github.io/pc-setup-guide/

## What's inside

- Step by step Windows setup: clean install or reset, local account, updates
- Debloat and privacy configuration (WinUtil, O&O ShutUp10)
- BIOS and driver update workflow
- Manufacturer software replacement, with lightweight community alternatives per brand
- A categorised app checklist with persistent progress, saved automatically in the browser
- Google Drive backup setup
- Development environment setup: Git, VS Code, Python, GitHub Desktop, Claude Code
- A growing keyboard shortcuts reference

## How to use it

Open the link above, or `index.html` in any browser. Follow the steps in order and
check off apps as you install them. Progress is saved locally, no account needed.
Commands can be copied straight from the code blocks with the built in copy button.

Progress is stored per browser, so a phone and a laptop each keep their own.

## How to edit it

Plain HTML, CSS and JavaScript. No build tools, no framework. Open it in any code
editor and change the text, colours or app list directly. The app list and
keyboard shortcuts sections are meant to be updated per device.

## Why this exists

Setting up a new machine well takes real research: which OEM software to skip,
which community tool replaces it, which settings are worth touching. This exists
so that research does not have to be redone from scratch every time, on this
machine or the next one.
